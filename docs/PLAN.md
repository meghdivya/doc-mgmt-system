# Development plan

## Goal
Ship a local-only marketplace MVP with the smallest useful feature set.

## Milestones

### 1. Setup and foundation
- Create project structure
- Define local-only architecture
- Add docs and task tracking

### 2. Product catalog MVP
- Create product records
- List products
- Validate stock and pricing

### 3. Orders and stock workflow
- Accept orders against available stock
- Reduce inventory after sale
- Reject invalid or oversold quantities

### 4. Basic dashboard
- Count products and orders
- Sum revenue
- Track low-stock items

## Delivery target
A working local version that can be run and explained without any external services.

## Notes
This plan keeps the scope minimal, with each feature tested before moving to the next milestone.
